# Vintage Barber Shop Website

A responsive front-end website for a fictional vintage barbershop, built as part of my JavaScript certification learning program.
This project gave me practical experience applying HTML, CSS, and vanilla JavaScript to create an interactive, multi-section business website.

## Features

- Responsive navigation with a mobile menu
- Dynamic service cards generated with JavaScript
- Service-details modal interactions
- Call-to-action booking flow
- Interactive appointment calendar with:
  - Month navigation
  - Past-date and Sunday availability restrictions
  - Available time-slot selection
  - Booking confirmation and booked-slot handling
- Dynamic business-hours messaging based on the current day and time
- Responsive layout for desktop and mobile screens

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive design with CSS Grid and Flexbox

## Learning Goals

This project was completed with instructor guidance as part of my JavaScript certification coursework. I used it to practice:

- DOM selection and manipulation
- Event listeners and user interaction
- Dynamically creating and updating page elements
- Date and time logic in JavaScript
- Form validation
- UI state management for bookings and modal windows
- Building responsive user interfaces

## Note

This is a front-end learning project. Appointment data is handled in the browser during the active session and is not connected to a production database or booking service.
